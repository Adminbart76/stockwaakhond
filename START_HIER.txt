STOCKWAAKHOND V7 - START HIER

1. Pak de ZIP uit.
2. Open de map StockWaakhond_V7.
3. Klik in de adresbalk van Verkenner.
4. Typ: powershell
5. Druk Enter.

Voer uit:

py -m venv .venv

.\.venv\Scripts\Activate.ps1

python -m pip install -r requirements.txt

python -m streamlit run app.py


BELANGRIJK:
Na het eerste vastgelegde forward-signaal ontstaat de map:

forward_log

Bewaar die map. Daarin staat het append-only forward-logboek.
